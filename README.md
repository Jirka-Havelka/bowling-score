# Bowling Score

Simple mobile web app for keeping bowling scores by hand when the lane display doesn't work.

- Up to 9+ players, editable names
- Tap the number of pins knocked down; strikes, spares and the 10th frame are scored automatically
- Impossible values are disabled, "Zpět" undoes the last roll
- Live leaderboard with podium ("Pořadí")
- Scores are saved in the browser, so a reload doesn't lose the game
- Keeps the screen awake where the phone allows it

Single file, no build step: open `index.html` or serve it via GitHub Pages.

UI is in Czech.
